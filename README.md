# Ant Colony Simulator

A browser-based ant colony simulator inspired by classic colony simulation games.

## Live Site

https://thug0dad-sudo.github.io/ant-colony-simulator/

## Current Features

- Browser playable
- Ant spawning
- Food gathering
- Food storage
- Pheromone trails
- Spider predators
- Queen colony

## Controls

- Left Click: Place food
- Right Click: Spawn ant
- Space: Spawn spider
